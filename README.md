# 옛날 사진 복원기

오래된 사진·저해상도 사진을 복원하는 프로그램입니다. AI 처리는 모두 내 컴퓨터 안에서 이뤄집니다.

## 실행

| 파일 | 용도 |
|---|---|
| `실행.bat` | 이 컴퓨터에서만 쓰기. 브라우저에 화면이 열립니다 (http://127.0.0.1:7860). |
| `공개링크로_실행.bat` | 다른 컴퓨터·휴대폰에서도 쓰기. `https://….trycloudflare.com` 공개 링크를 만들어 창에 보여 주고 클립보드에 복사합니다. |

- 처음 실행하면 프로그램 환경(`.venv`)을 만들고 필요한 패키지를 설치합니다. Python 3.12가 필요합니다 (`winget install Python.Python.3.12`).
- 각 기능을 처음 쓸 때 AI 모델을 내려받습니다 (모두 받으면 약 2GB, `models` 폴더).
- 결과는 `결과` 폴더에 PNG로 저장됩니다.

### 공개 링크 사용 시 알아 둘 점

- 처음 한 번 [cloudflared](https://github.com/cloudflare/cloudflared)를 자동으로 설치합니다 (가입 불필요).
- **비밀번호가 없습니다.** 링크를 아는 사람은 누구나 쓸 수 있으니 믿을 수 있는 사람에게만 보내세요.
- 사진은 Cloudflare 터널을 거쳐 이 컴퓨터로 전달됩니다. AI 처리는 여전히 이 컴퓨터에서만 합니다.
- 창을 닫으면 프로그램과 링크가 함께 꺼지고, 다시 켜면 링크 주소가 바뀝니다.

## 사용 흐름

1. **사진 한 장 복원** 탭에서 사진을 올립니다. 긁힌 곳은 브러시로 칠하면 지워 줍니다.
2. 오른쪽 설정 칸마다 있는 **✨ 자동**을 누르면 사진을 분석해 추천값을 넣어 줍니다 (맨 위 **전체 자동**은 모든 칸을 한 번에). 확인한 뒤 원하는 만큼 더 조절하고, 마음에 안 들면 **↺ 초기화**로 되돌립니다.
3. **복원 시작** → 왼쪽 칸에서 복원 전/후를 비교합니다.
4. 아래 **마무리**에서 색감 보정과 트리밍을 하고 **마무리 적용해서 저장**을 누릅니다. 여기도 칸마다 자동·초기화 버튼이 있습니다.
5. 여러 장을 같은 느낌으로 하려면, 한 장으로 설정을 찾은 뒤 **여러 장 한꺼번에** 탭에서 **설정 그대로 가져오기**를 누르고 사진들을 올립니다.

## 기능

| 기능 | 방법 |
|---|---|
| 긁힘·얼룩 제거 | 자동 감지(규칙 기반) + 브러시로 직접 칠하기 → LaMa AI로 메우기 |
| 색 바램 보정 | 대비 복원 + 누런 색조 중화 |
| 해상도 높이기 | **자동(기본)**: 작은 사진만 긴 변 약 4000px까지 키우고, 이미 큰 사진은 그대로 둠. 2배·4배도 고를 수 있지만 긴 변 8000px까지만. 방식은 **Nomos8k (디테일 살리기, 기본)** 또는 Real-ESRGAN (매끈하게) |
| 얼굴 복원 | YuNet으로 얼굴 찾기 → GFPGAN 1.4 또는 CodeFormer (큰 얼굴은 업스케일러로 한 번 더 키워 선명하게) |
| 흑백 컬러화 | DDColor |
| 색감 보정 (마무리) | 프리셋 9종 + 노출·대비·밝은/어두운 영역·색온도·색조·채도·생동감·세피아·바랜 느낌·비네팅·선명도, 실시간 미리보기 |
| 트리밍 (마무리) | 스캔 테두리(흰 여백·검은 띠) 자동 제거, 비율 맞추기(1:1, 3:2, 4:3, 16:9, 4:5 등), 위·아래·왼쪽·오른쪽 여백 조절, 잘릴 부분 미리보기 |
| 자동 설정 | 칸마다 사진을 분석해 추천값 제안 (긁힘 양, 대비·색조, 크기·잡티, 얼굴 수·선명도, 흑백 여부, 밝기, 색 쏠림, 흐림, 테두리) |
| 여러 장 한꺼번에 | 한 장 복원과 똑같은 복원 옵션·색감·트리밍으로 일괄 처리 + ZIP. 휴대폰 사진의 회전 정보(EXIF) 반영 |

처리 순서: 긁힘 제거 → 색 바램 보정 → 해상도 → 얼굴 → 컬러화 → (트리밍 → 색감 보정)

트리밍을 색감 보정보다 먼저 하는 이유: 비네팅·자동 색 균형이 잘린 뒤의 사진 테두리를 기준으로 적용되게 하려고.

## 구조

- `app.py` — Gradio 웹 화면
- `restorer/pipeline.py` — 복원 처리
- `restorer/grading.py` — 색감 보정 (AI 없이 즉시 계산)
- `restorer/trim.py` — 트리밍, 스캔 테두리 감지
- `restorer/auto.py` — '✨ 자동' 버튼의 사진 분석과 추천값
- `restorer/models.py` — 모델 다운로드, ONNX Runtime 세션 (DirectML GPU, 실패하면 CPU로 재시도)

## 참고

- AMD/Intel/NVIDIA 그래픽카드 모두 DirectML로 가속됩니다. LaMa(긁힘 메우기)만 DirectML이 지원하지 않는 연산을 써서 CPU에서 돌아갑니다. 급할 때는 메우는 방식을 "빠름 (OpenCV)"으로 바꾸세요.
- 이미 큰 사진(예: 휴대폰 사진 2500만 화소)을 더 키우면 몇 분씩 걸리고 파일이 100MB를 넘지만, 옛날 사진에는 그만한 디테일이 없어 얻는 게 거의 없습니다. 그래서 해상도 기본값이 '자동'입니다.
- 얼굴 복원과 컬러화는 AI가 그럴듯하게 **추측해서 그린** 결과라 실제와 다를 수 있습니다.
- 자동 긁힘 감지는 얼굴 안의 짧은 긁힘은 주름과 구분하기 어려워 일부러 건너뜁니다. 그런 곳은 브러시로 칠하세요. 옷감·배경 무늬가 많은 사진은 감지가 엉뚱한 곳까지 잡을 수 있어서, ✨ 자동은 이런 사진에서 자동 제거를 끄고 브러시를 권합니다.
- 모델 라이선스: GFPGAN(Apache-2.0), Real-ESRGAN(BSD-3), DDColor(Apache-2.0), LaMa(Apache-2.0), YuNet(MIT), **CodeFormer는 비상업적 용도만 허용(S-Lab License)**.
