# 옛날 사진 복원기

오래된 사진·저해상도 사진을 복원하는 프로그램입니다. 모든 처리는 내 컴퓨터 안에서만 이뤄지고, 사진이 외부로 전송되지 않습니다.

## 실행

`실행.bat`을 더블클릭하면 브라우저에 화면이 열립니다 (http://127.0.0.1:7860).
각 기능을 처음 쓸 때 AI 모델을 내려받습니다 (모두 받으면 약 2GB, `models` 폴더). 결과는 `결과` 폴더에 PNG로 저장됩니다.

## 기능

| 기능 | 방법 |
|---|---|
| 긁힘·얼룩 제거 | 자동 감지(규칙 기반) + 브러시로 직접 칠하기 → LaMa AI로 메우기 |
| 색 바램 보정 | 대비 복원 + 누런 색조 중화 |
| 해상도 높이기 (2배/4배) | **Nomos8k (디테일 살리기, 기본)** 또는 Real-ESRGAN (매끈하게) |
| 얼굴 복원 | YuNet으로 얼굴 찾기 → GFPGAN 1.4 또는 CodeFormer (큰 얼굴은 업스케일러로 한 번 더 키워 선명하게) |
| 흑백 컬러화 | DDColor |
| 색감 보정 (복원 후) | 프리셋 9종 + 노출·대비·밝은/어두운 영역·색온도·색조·채도·생동감·세피아·바랜 느낌·비네팅·선명도, 실시간 미리보기 |
| 여러 장 한꺼번에 | 같은 설정으로 일괄 처리 + ZIP |

처리 순서: 긁힘 제거 → 색 바램 보정 → 해상도 → 얼굴 → 컬러화 → (색감 보정)

## 구조

- `app.py` — Gradio 웹 화면
- `restorer/pipeline.py` — 복원 처리
- `restorer/grading.py` — 색감 보정 (AI 없이 즉시 계산)
- `restorer/models.py` — 모델 다운로드, ONNX Runtime 세션 (DirectML GPU, 실패하면 CPU로 재시도)

## 참고

- AMD/Intel/NVIDIA 그래픽카드 모두 DirectML로 가속됩니다. LaMa(긁힘 메우기)만 DirectML이 지원하지 않는 연산을 써서 CPU에서 돌아갑니다.
- 얼굴 복원과 컬러화는 AI가 그럴듯하게 **추측해서 그린** 결과라 실제와 다를 수 있습니다.
- 자동 긁힘 감지는 얼굴 안의 짧은 긁힘은 주름과 구분하기 어려워 일부러 건너뜁니다. 그런 곳은 브러시로 칠하세요.
